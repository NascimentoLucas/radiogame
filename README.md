# Radio Trucker

A cozy, async-multiplayer game about a truck driver who finds work by tuning a radio. See [radio_trucker_gdd.md](radio_trucker_gdd.md) for the design and [CLAUDE.md](CLAUDE.md) for development guidelines.

## Run

```bash
npm install
npm run web       # PC / browser
npm run android   # needs a dev build (native audio module): npx expo run:android
```

## Checks

```bash
npm run typecheck
npm run lint
npm test
```
